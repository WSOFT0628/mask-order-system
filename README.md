# 口罩訂購助手 v3.6.2

「口罩訂購助手」是一套適合公司、團體與親友團購使用的口罩訂單管理系統，整合智慧儀表板、賣家代訂、公開活動訂購、買家訂單管理、價目表與系統設定。

## 正式網址

- [管理端](https://wsoft0628.github.io/mask-order-system/)
- [買家訂購頁](https://wsoft0628.github.io/mask-order-system/order.html)
- [買家訂單查詢](https://wsoft0628.github.io/mask-order-system/my-orders.html)

## 主要功能

### 智慧儀表板

- 顯示開放中活動、待確認訂單、買家訂購盒數與訂單金額
- 集中查看目前活動、最近買家訂單與待處理提醒
- 快速前往代訂開單、建立活動、買家訂單及系統設定
- 左上 Logo 與系統名稱可隨時返回智慧儀表板首頁

### 代訂作業

- 整合「代訂開單、代訂結帳、代訂紀錄」選單
- 導覽列即時顯示已選商品種類、總盒數與訂單紀錄數
- 支援商品搜尋、直接輸入數量及即時計算金額
- 可由管理端協助電話或私下委託者建立訂單

### 活動與買家訂單

- 建立多個團購活動並設定開放時間、截止時間與修改規則
- 自動產生活動網址與 QR Code，可複製網址或下載 QR Code
- 依活動查看買家訂單及保留已結束、停用活動紀錄
- 支援全選、多選、批次更新狀態與永久刪除
- 訂單狀態顏色識別、分裝單列印、CSV 與廠商 Excel 匯出
- 首頁與導覽列的買家訂單數量可即時更新

### 商品與快捷篩選

- 管理商品分類、名稱、款式、價格、顯示色與缺貨狀態
- 自訂快捷按鈕名稱、對應分類、裝飾色及搜尋關鍵字
- 快捷設定會同步套用至管理端代訂頁與客戶活動訂購頁
- 例如設定「藍色／全部／藍、藍色」，即可篩選藍色相關商品
- 編輯快捷設定時可更新或取消編輯

### 買家端

- 透過活動專屬網址或 QR Code 進入訂購頁
- 填寫姓名、電話與備註後挑選商品
- 即時顯示商品數量、商品金額、運費、稅額與總額
- 訂單送出後保存訂單編號與專屬修改連結
- 可用「訂單編號＋完整電話」或「姓名＋完整電話」查詢
- 依活動及訂單狀態查看、修改或取消訂單

### 系統與安全

- Supabase 雲端同步、成員、帳號與角色權限管理
- 系統設定採頁籤分類，降低頁面長度
- 通知異常診斷與安全紀錄
- 本機備份、還原、暫存清理與原廠設定

## 建置與升級

### 1. GitHub Pages

1. 在儲存庫開啟 **Settings → Pages**。
2. Source 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選擇 **/(root)**。
4. 正式網站由 `index.html` 發布。

### 2. Supabase SQL

新環境先執行初始化 SQL，再依版本順序執行升級檔。已經成功執行的升級檔不需重複執行。

目前需依實際環境執行至最新版本的升級 SQL；既有環境請勿重複建立相同資料表或政策。

### 3. Edge Functions

- `mask-public-order`：活動資料、快捷設定、買家下單、查詢、修改與取消；`Verify JWT` 維持關閉。
- `mask-user-admin`：帳號與權限管理；JWT 驗證維持開啟。

修改 `mask-public-order` 原始碼後必須在 Supabase 重新 **Deploy function**；只更新 GitHub 檔案不會自動部署 Edge Function。單純修改 `index.html`、`order.html` 或 `my-orders.html` 不需重新執行 SQL。

## 安全注意事項

- 不要將 Database password、Secret key 或 `service_role` key 放入 HTML、GitHub 或瀏覽器程式碼
- HTML 只能使用可公開的 Supabase Publishable key
- `SUPABASE_SERVICE_ROLE_KEY` 只能由 Edge Function 後端讀取
- 買家歷史訂單不允許只用姓名或只用電話查詢
- 永久刪除訂單無法復原，一般紀錄建議優先使用取消或封存
